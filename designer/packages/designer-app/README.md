# designer-app

Designer, a desktop tool for authoring a data dictionary: validation rules, types,
fields, record structures and the schemas that group them. Built on tkinter and
`designer-model`.

    designer [model.json]

tkinter is part of Python's standard library but packaged separately on some
systems — on Debian and Ubuntu install `python3-tk`; the application says so if
it is missing.

Documentation, the specification and worked examples:
https://github.com/maarten-boot/designer
